==============================================================================
6. EXTERNAL SERVICES (no installation, network calls only)
==============================================================================

OpenRouter                  https://openrouter.ai
  API for the AI assistant. Requires an API key.
  Free tier available; paid models start at $0.15 / million tokens.

OpenStreetMap Tiles         https://tile.openstreetmap.org
  Free base map tiles. No key required.

OSRM (routing engine)       https://router.project-osrm.org
  Free road geometry for smooth bus movement. No key required.
  If unreachable, the simulator falls back to straight lines.

Overpass API                https://overpass-api.de
  Free OpenStreetMap POI queries for the place finder.
  If unreachable, the backend serves a built-in demo set.

Esri World Imagery          https://server.arcgisonline.com
  Free satellite tiles for the map toggle. No key required.

Google Maps links           https://maps.google.com
  "Open navigation" links only. No API key needed for URL scheme.

7. BROWSER APIs USED (nothing to install)
==============================================================================

navigator.geolocation
  Real-time user location on the map and place finder.

BarcodeDetector (Chrome, Edge, recent Safari)
  QR scanning at /admin/validate. Falls back to manual entry
  everywhere else.

localStorage
  Persists JWT token, user profile, and AI chat session.

print() via window.print()
  A4 ticket printing on the tickets page.


==============================================================================
8. ONE-SHOT INSTALL SCRIPT
==============================================================================

Copy-paste this into PowerShell from the project root. It installs
everything in one go.

--- BEGIN ---

Write-Host "Installing backend..."
cd backend
npm install
cd ..

Write-Host "Installing frontend..."
cd frontend
npm install
cd ..

Write-Host "Installing simulator..."
cd simulator
npm init -y
npm install dotenv jsonwebtoken
cd ..

Write-Host "Setting up Python..."
cd ml
python -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install --upgrade pip
pip install -r requirements.txt
Write-Host "Training model (takes 1-3 minutes)..."
python generate_dataset.py
python train.py
deactivate
cd ..

Write-Host "Setting up database..."
cd backend
npm run db:init
npm run seed
mysql -u root routeview < src\db\intercity_schema.sql
npm run seed:intercity
cd ..

Write-Host ""
Write-Host "DONE. Now start the four services:"
Write-Host "  Terminal 1: cd ml ; .\.venv\Scripts\Activate.ps1 ; uvicorn service:app --port 8000"
Write-Host "  Terminal 2: cd backend ; npm run dev"
Write-Host "  Terminal 3: cd frontend ; npm run dev"
Write-Host "  Browser:    http://localhost:3000"

--- END ---

==============================================================================
11. WHAT'S NOT NEEDED
==============================================================================

You do NOT need:
  · Docker or any container runtime
  · A cloud account (Vercel, AWS, GCP, etc.)
  · A paid domain
  · A paid map API key (OpenStreetMap and Esri tiles are free)
  · A paid AI key (OpenRouter has free-tier models)
  · A message queue, Redis, or any background service
  · Git (unless you want version control)
  · Any compiler, build tool, or native extension

The whole system runs on one Windows machine with XAMPP and Node/Python
installed. Everything else is public HTTP APIs.
